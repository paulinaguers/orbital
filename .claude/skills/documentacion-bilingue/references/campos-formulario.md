## Campos (todo en inglés)
| Campo | Qué escribir |
| --- | --- |
| Project Name | ORBITAL |
| High-Level Project Summary | Qué desarrollamos, cómo responde al desafío, por qué importa (3–5 oraciones) |
| Link to Project Demo | Video ≤ 30 s en YouTube o Drive, público, sin login |
| Link to Final Project | Repo de GitHub público |
| Detailed Project Description | Qué hace, cómo funciona, beneficios, objetivos, herramientas y lenguajes |
| Use of Super Intelligence (SI) | Declaración de SI (plantilla). No la ven los jueces |
| NASA Data | NASA-STD-3001 (umbrales), riesgos del NASA HRP (un riesgo por indicador), Standard Measures y ARCHeR (qué se mide en vuelo), números publicados que usa el simulador |
| Space Agency Partner Data and Other References | CSA (Bio-Monitor, Space Health, Vascular, Radi-N2, CANS) + todas las fuentes clínicas + librerías + herramientas de SI |

Al enviar: tildar "Terms and Conditions" y "Confirm All Work is Original"; verificar el banner.

## Criterios del jurado (1 a 5 cada uno, mismo peso)
Impact · Creativity · Validity · Relevance (datos de NASA como parte central) · Presentation (demo + proyecto completo).
