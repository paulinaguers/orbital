# Submission on spaceappschallenge.org (official guides of 13/11/2026)

Source: Project Submission Guide and Judging & Awards Guide (PDFs in `docs/guias-nasa/`).

## Deadlines
- The Project tab opens on Sat 14/11 at 9:00 (site time). What is saved is only visible to the team until it is submitted.
- Closes: Sun 15/11 at 23:59, Rosario time. It can be resubmitted until then; the last submission counts.
- Global nominees 3/12/2026 · finalists 17/12/2026 · winners 26/1/2027.

## Fields (all in English)
| Field | What to write |
| --- | --- |
| Project Name | ORBITAL |
| High-Level Project Summary | What we built, how it answers the challenge, why it matters (3–5 sentences) |
| Link to Project Demo | Video ≤ 30 s on YouTube or Drive, public, no login |
| Link to Final Project | Public GitHub repo |
| Detailed Project Description | What it does, how it works, benefits, goals, tools and languages |
| Use of Super Intelligence (SI) | AI-use statement (template). Not seen by the judges |
| NASA Data | NASA-STD-3001 (thresholds), NASA HRP risks (one risk per indicator), Standard Measures and ARCHeR (what is measured in flight), published numbers used by the simulator |
| Space Agency Partner Data and Other References | CSA (Bio-Monitor, Space Health, Vascular, Radi-N2, CANS) + every clinical source + libraries + AI tools |

When submitting: tick "Terms and Conditions" and "Confirm All Work is Original"; check the banner.

## Demo video (≤ 30 s; going over disqualifies the project from global judging)
- 0:00 Who we are (The Foxhole Court)
- 0:02 The challenge and why we chose it
- 0:05 Name and tagline
- 0:10 How it works: the app on screen, the astronaut's experience, how NASA and CSA data are used
- 0:20–0:30 The future: what it could do for a mission to Mars
- Spoken in Spanish or English, **English subtitles required**. No minors under 18, no NASA logos. If anything in the video is AI-generated, a visible watermark.

## Judging criteria (1 to 5 each, same weight)
Impact · Creativity · Validity · Relevance (NASA data as a central part) · Presentation (demo + complete project).
